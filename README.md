# 🐦 Mengenal Burung Lebih Dekat - AR Edukasi

Website edukasi interaktif berbasis Augmented Reality untuk anak usia 7-12 tahun.

## 🚀 Fitur Utama

- **Informasi Burung** - Pelajari berbagai jenis burung lengkap dengan fakta unik
- **AR Camera** - Lihat burung 3D di dunia nyata menggunakan kamera
- **Quiz Interaktif** - Uji pengetahuan tentang burung
- **Progress Tracking** - Pantau perkembangan belajar

## 📦 Teknologi

- HTML5, CSS3, JavaScript
- A-Frame + AR.js untuk Augmented Reality
- Model 3D format .glb/.gltf
- LocalStorage untuk progress

## 🛠️ Cara Menjalankan

### Lokal Development
1. Clone repository ini
2. Jalankan dengan live server (contoh: Live Server VSCode)
3. Buka `index.html` di browser
4. Untuk AR, gunakan HTTPS (ngrok/localtunnel) atau deploy

### Deploy ke Netlify/Vercel
1. Upload semua file ke Netlify/Vercel
2. Tidak perlu build, langsung deploy
3. Pastikan menggunakan HTTPS untuk akses kamera
